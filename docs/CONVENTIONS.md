# Конвенции (черновик — уточняется по мере проверки)

## Структура проектов баз

- Корневая папка проектов: `PROJECTS_ROOT` (по умолчанию у владельца — `C:/hemes`).
- Каждый проект — отдельный git-репозиторий: `{PROJECTS_ROOT}/<проект>/`.
- `<проект>/src/cf` — выгрузка основной конфигурации (**read-only, НЕ в git**).
- `<проект>/src/cfe/<ИмяРасширения>/` — папка на каждое расширение (**только это в git**).
- `<проект>/notes/` — проектная память (что за база, версии, реестр доработок).
- `<проект>/reports/` — отчёты анализа (вне git).
- `<проект>/.bsl-language-server.json` — правила bslc (в git).
- `<проект>/AGENTS.md` — правила для агента (в git).

## Инфраструктура

- `{PROJECTS_ROOT}/tools/` — всё, что не Docker и не базы: конфиги, sqlite-контексты, служебные репозитории, обработки, `projects.json`, `.env`.
- Порт-паспорт: 6002 — 1c-buddy (Напарник), 6003 — мост; 8080 — SearXNG (не занимать без нужды), 1414 — запрещён.

## Git

- Один репо на базу; ветка на расширение (`feat/<расширение>-<доработка>`).
- Conventional Commits: `feat(...)`, `fix(...)`, `docs:`, `chore:`.
- Коммит = осмысленный шаг; агент коммитит только по явной команде владельца.
