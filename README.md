# 1c-hermes-ninja-kit

Набор инструментов для ИИ-экосистемы разработки 1С: ставит и настраивает всё окружение (oscript, docker-анализатор bslc, контуры MCP), создаёт проекты баз по конвенции и даёт агентам (Hermes и др.) единый интерфейс для анализа кода расширений.

> **Статус: WIP** — каркас + пошаговое развёртывание в процессе. Каждый шаг руководства проверяется реальным исполнением на машине (см. `docs/INSTALL.md`).

## Что внутри

```
install/     — install.sh: идемпотентная установка/проверка окружения
scripts/     — рабочие инструменты: bsl-check, ninja (new/list/scan), registry
templates/   — эталоны: .gitignore базы, .bsl-language-server.json, AGENTS.md, notes
docs/        — INSTALL.md (проверена исполнением), CONVENTIONS.md, DECISIONS.md
```

## Быстрый старт (после релиза)

```bash
git clone <url> 1c-hermes-ninja-kit
cd 1c-hermes-ninja-kit
./install/install.sh            # всё поставит/проверит, спросит корневую папку проектов
ninja new <имя-базы>            # создать проект по конвенции
ninja check <имя-базы> <расширение>   # прогнать bslc
```

## Принципы

- **Идемпотентность**: повторный запуск установщика ничего не ломает.
- **Никаких секретов**: токены только из `.env`/переменных окружения; стоп-лист `.env` в gitignore.
- **Базы — снаружи**: репозиторий знает конвенцию `{корень}/<проект>/src/cf + src/cfe`, но не содержит ни одной базы.
- Выгрузка основной конфигурации (`src/cf`) в git **не** заносится (огромная, восстанавливается); в git — только расширения, конфиги и документация.
