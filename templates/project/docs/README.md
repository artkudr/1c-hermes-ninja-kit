# Общая документация проекта

Каталог `docs/` — для документации **вне задач**: инструкции, стандарты,
памятки по базе, договорённости. Документы конкретной задачи — в её папке
`tasks/Задача_N/`, сюда не кладём.

## Как организовывать

- По темам: `docs/<тема>/…` (например `docs/обмены/`, `docs/печать/`).
- Крупный материал начинаем с `README.md` в подпапке (оглавление темы).
- Даты и версии — в начале файла (шапка).
